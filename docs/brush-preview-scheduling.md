# Interactive brush previews

The brush list and large settings preview share one Qt event-loop queue. There are no background rendering threads and no concurrent access to material caches. Only the active job owns a raster stroke; queued jobs retain just their immutable brush definitions and requested colors/dimensions.

Each timer turn advances at most eight iterator operations and checks a four-millisecond time budget between operations. A single image decode, raster primitive or final composition cannot be interrupted; the budget limits repeated work within a turn rather than promising a hard upper bound for every callback. The queue pauses while the associated canvas has an active Brush stroke. Settings edits cancel the previous request immediately, before the preview debounce expires. Hiding the preview or closing the preset popup releases its active iterator. Settings previews take priority over popup thumbnails, and cancelled results cannot replace a newer preview.

`iter_brush_preview()` retains the same raster renderer, input path, pressure/tilt samples, palette colors and seed 42 as exported previews. It yields between dabs and defers composition until the final image. For post-correction or ending-taper replay, a scheduler-only prepass computes the same final input sequence and lengths that `RasterBrushStroke.finish()` would use. It then paints that final path once, avoiding an invisible initial render and an uninterruptible full-stroke replay. Iterator cancellation clears the renderer's working planes and temporary data.

The iterator uses existing raster lifecycle primitives rather than a separate preview painting algorithm. If that lifecycle changes, keep the reference tests comparing its final pixels with public `begin()`, `add()` and `finish()`. Coverage includes wet pickup, dual brushes with independent stabilization, post-correction, percentage and length tapers, ribbons, spray, live watercolor edges and transparent-color erasing. `render_brush_preview()` remains a synchronous helper for exported artifacts and tests; it simply exhausts the same iterator. `BrushPreview._render()` is an asynchronous UI submission.

The shared 64-image cache keys render-relevant settings and palette colors. Large PNG strings use process-local immutable string fingerprints, avoiding full base64 JSON serialization and avoiding retained image strings in cache keys. Source provenance and compatibility notes do not affect the rendered image.

Fake slow-iterator tests verify that other Qt events run between preview steps, live drawing pauses work, newer requests replace older ones, hidden widgets and closed popups cancel work, and only one active job retains raster working memory. A focused preview/UI run passed 67 tests after this change; the renderer's deferred-composition regressions are covered separately.
