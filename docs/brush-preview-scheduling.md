# Interactive brush previews

The thumbnail warmer and large settings preview share one Qt event-loop queue. There are no background rendering threads and no concurrent access to material caches. Only the active job owns a raster stroke; queued jobs retain just their immutable brush definitions and requested colors/dimensions. The preset picker itself paints saved images and never requests raster work when opening or scrolling.

Each timer turn advances at most eight iterator operations and checks a four-millisecond time budget between operations. A single image decode, raster primitive or final composition cannot be interrupted; the budget limits repeated work within a turn rather than promising a hard upper bound for every callback. The queue pauses while the associated canvas has an active Brush stroke. Settings edits cancel the previous live-preview request immediately, before the preview debounce expires. Hiding the live preview releases its active iterator. Thumbnail warming continues when the picker closes or the brush page is hidden, so the next open can use its saved results. Settings previews take priority over thumbnail warming, and cancelled results cannot replace a newer preview.

`iter_brush_preview()` retains the same raster renderer, input path, pressure/tilt samples, palette colors and seed 42 as exported previews. It yields between dabs and defers composition until the final image. For post-correction or ending-taper replay, a scheduler-only prepass computes the same final input sequence and lengths that `RasterBrushStroke.finish()` would use. It then paints that final path once, avoiding an invisible initial render and an uninterruptible full-stroke replay. Iterator cancellation clears the renderer's working planes and temporary data.

The iterator uses existing raster lifecycle primitives rather than a separate preview painting algorithm. If that lifecycle changes, keep the reference tests comparing its final pixels with public `begin()`, `add()` and `finish()`. Coverage includes wet pickup, dual brushes with independent stabilization, post-correction, percentage and length tapers, ribbons, spray, live watercolor edges and transparent-color erasing. `render_brush_preview()` remains a synchronous helper for exported artifacts and tests; it simply exhausts the same iterator. `BrushPreview._render()` is an asynchronous UI submission.

The shared 64-image memory cache serves live previews and active rendering jobs. Large PNG strings use process-local immutable string fingerprints, avoiding full base64 JSON serialization and avoiding retained image strings in cache keys. Source provenance and compatibility notes do not affect the rendered image.

Preset thumbnails additionally use a durable cache in `brush-thumbnails` beside the preferences JSON. A stable SHA-256 fingerprint covers rendering fields, main/secondary tips and textures, normalized numeric values, image digests, dimensions, fixed ink color, and `THUMBNAIL_RENDER_VERSION`. Brush IDs, names, source metadata and compatibility notes do not change the pixels. Renaming or duplicating an unchanged preset therefore reuses the same image. A bounded digest memo retains no original PNG strings. Bump the thumbnail renderer version and rebuild bundled previews whenever the preview path or raster renderer changes its visual output.

`BrushThumbnailStore.sync()` runs at brush-control initialization and after preset refreshes/imports/edits. It loads existing 160×64 PNGs, queues only missing/changed definitions, and discards superseded pending work. One thumbnail at a time enters the shared cooperative queue at lower priority than live previews. Completed images are atomically published before the grid receives its update. Invalid or missing derived files can be regenerated without changing preferences or original brush art; failed previews are shown explicitly instead of repeatedly retried during scrolling. All 14 built-in previews are bundled under `comic_editor/core/data/brush-thumbnails` for immediate use in a fresh install.

`BrushPresetGrid` replaces the narrow combo popup with an expanded overlay. Its tile delegate paints a cached thumbnail above a wrapped name; search, selection, scrolling and reopening only touch existing icons. Columns fit the viewport width, including its scrollbar. The current preset scrolls into view on open; click/Enter selects it and Escape/outside clicks close the overlay. The closed preset field keeps a normal text-control height.

Fake slow-iterator tests verify that other Qt events run between preview steps, live drawing pauses work, newer requests replace older ones, hiding live previews cancels work, closing the grid preserves thumbnail warming, and only one active job retains raster working memory. Persistent-cache tests cover 75 brushes beyond the memory-cache limit, a fresh cache owner after restart, changed/renamed presets, in-place edits, cancellation of superseded output, corrupt-file recovery, imported brushes prepared before opening, palette independence, grid selection/scrolling/reopening without rendering, and the complete bundled set. The renderer's deferred-composition regressions are covered separately.
