PROGRAM MAP - Vertical Comic Editor (Webtoon Maker)
====================================================

1. PROGRAM OVERVIEW AND GOAL
----------------------------

The Vertical Comic Editor is a native desktop application for creating vertically
scrolling webtoon comics. Built with PySide6 (Qt for Python), it provides a
complete drawing and composition environment purpose-built for the 1080px-wide,
infinitely-scrollable format used by webcomic platforms.

The program manages series (collections of chapters), each chapter being a
vertically-extending canvas of 1080px width. Within each chapter, the artist
creates a hierarchy of:

  - Page layers: rectangular regions arranged vertically down the canvas.
  - Bounded layers: nested rectangles, circles, or custom shapes that clip their
    children. Compound shapes can combine additive/subtractive/ignored child
    branches into a single Boolean mask. Additional contours are supported.
  - Fill layers: non-destructive colored fills inheriting their parent's shape.
  - Open shape layers: freeform variable-width stroked lines with caps.
  - Raster objects: sparse 256x256-tiled bitmap drawing areas supporting
    pressure-sensitive pencil and eraser tools.
  - Text objects: in strict (fit-to-parent/compound with alignment/margins) or
    free (projective quad transform) layout modes. Name derived from content.
  - Vector Drawing objects: pressure-sensitive cubic Bézier vector strokes with
    variable width and opacity, plus owned Vector Fill children.
  - Vector Fill objects: bounded face fills owned by a Vector Drawing, with
    close-gaps, narrow-area handling, enclose mode, and area scaling.

All edits are backed by a full undo/redo command stack with focused object-patch
commands for vector edits. The application saves projects as portable folders
with atomic, versioned chapter saves and automatic recovery from interrupted
writes.

Core design principles:
  - Non-destructive: masks, fills, compound shapes, and layer opacity compose
    without modifying child data.
  - Sparse tiles: raster strokes are stored as 256x256 RGBA tiles, allocated
    only where the artist draws.
  - Versioned migration: documents carry a schema version; legacy formats are
    migrated on load up to V7.
  - Extensible registries: object and bound types can be registered at runtime.
  - Portable persistence: series folders are self-contained and relocatable.
  - Canonical colors: all colors normalized to #AARRGGBB for consistency.
  - Ribbon UI: contextual tool controls in a tabbed, scrollable ribbon.


2. TOOLS (INTERACTIVE MODES)
----------------------------

The application provides 16+ interactive tools, accessed via left toolbar buttons
and keyboard shortcuts:

  Object Select (S)    - Click to select entities (layers, objects, shapes,
                          vector strokes). Ctrl+click shows a candidate menu for
                          overlapping entities. Shapes selected by clicking near
                          their border (12px tolerance).

  Raster Pencil (P)    - Draw on a RasterObject with pressure-sensitive size
                          and opacity curves. Supports density, antialiasing,
                          stroke taper, and predictive ink. Contextual: draws
                          vector strokes on a VectorDrawingObject.

  Raster Eraser (E)    - Erase from a RasterObject (circular or square brush).
                          Auto-prunes empty tiles. Contextual: three vector
                          eraser modes (Stroke / Point / Intersection).

  Fill (F)             - On shapes: click border for outline, interior for fill.
                          On Vector Drawing: click/drag through faces to create
                          Vector Fill children behind its strokes. Enclose mode
                          creates one fill from a drawn enclosure.

  Text Edit             - Edit a TextObject. Click to position cursor, drag to
                          select. IME input, clipboard paste, local undo within
                          session. Drag edge midpoints in strict mode to change
                          margins.

  Transform (T)         - Free projective (8-handle) or uniform (scale around
                          opposite handle) transform. Grid snapping. Static
                          background cache for raster previews.

  Shape Edit (B)        - Edit a bounded layer's geometry. Select/drag nodes,
                          Bézier controls, gizmos (type toggle, handle lock,
                          roundness, thickness, delete, cap). Insert points.
                          Translate shapes. Rectangle layers: per-corner radius,
                          normal/free edit modes, edge dragging. Additional
                          contours: select and edit contour nodes. Compound
                          shapes: edit construction paths without child handles.

  Vector Edit           - Auto-activated when a Vector Drawing is selected.
                          Blue anchor circles for the selected stroke. Ctrl+click
                          extends stroke selection. Point drag, redraw, connect,
                          simplify via Vector Tools ribbon.

  Add Rectangle         - Drag to create a rectangular bounded layer. Uses
                          primary color for outline, secondary for fill.

  Add Circle            - Drag (center + radius point) to create an ellipse
                          bounded layer.

  Add Shape             - Click to place vector points. Drag to create Bézier
                          curves. Click first point to close a polygon. Press
                          Enter or double-click to commit an open line.

  Add Raster            - Drag to define raster frame size and position.

  Add Text              - Adds a TextObject to the active layer using the
                          active text preset's formatting.

  Add Fill              - Adds a fill layer with the active brush color.

  Add Vector Drawing    - Creates an editable VectorDrawingObject.

  Vector Redraw         - Redraws vector stroke thickness or opacity with
                          manual or point-select interaction. Apply to selected
                          points, selected strokes, or all strokes.

  Vector Connect        - Sweep across two endpoints to connect them with a
                          tangent bridge.

  Vector Simplify       - Simplifies selected or all vector curves by amount
                          (0-100%), preserving local shape.

Class: ChapterDocument
  The main document. Fields: chapter_id, name, width=1080, height=3240,
  background, grid, root_page_ids, layers (dict), objects (dict),
  schema_version.

  validate()
    Comprehensive invariant check (~200 lines):
    - Schema version <= SCHEMA_VERSION, width == CHAPTER_WIDTH.
    - No duplicate root page IDs.
    - All roots must be parentless page layers.
    - All layers: valid kind, valid compound_operation, fill layer constraints
      (requires parent, boundless leaf, requires color, no compound), bounded
      layer constraints, open shape constraints (open paths, no children
      allowed at validation time), compound_enabled not allowed for pages.
    - No entity appears in multiple parent children lists.
    - VectorFill objects excluded from child refs (owned by drawings).
    - Vector drawing/fill cross-validation: each fill owned by exactly one
      drawing, fill parent_layer matches owner's, fill in owner's fill_child_ids.
    - All objects have valid container layer (not fill).
    - Raster/Text invariants, geometry_reference validation.
    - Layer hierarchy is acyclic (DFS from each root page).
    - Expected entities match referenced entities (excluding fills in child refs).
