PROGRAM MAP - Vertical Comic Editor (Webtoon Maker)
====================================================

1. PROGRAM OVERVIEW AND GOAL
----------------------------

The Vertical Comic Editor is a native desktop application for creating vertically
scrolling webtoon comics. Built with PySide6 (Qt for Python), it provides a
complete drawing and composition environment purpose-built for the 1080px-wide,
infinitely-scrollable format used by webcomic platforms.

The program manages series (collections of chapters), each chapter being a
vertically-extending canvas of 1080px width. Within each chapter, the artist
creates a hierarchy of:

  - Page layers: drawn (rectangle/circle/custom-shape) regions arranged vertically.
    Pages are inserted by drawing them below the active page (drag-to-create),
    or via an Insert Page Gap tool that adds an orange 120px editable gutter.
    Dotted edges move individual page groups; the shaded band moves both groups.
  - Bounded layers: nested rectangles, circles, or custom shapes that clip their
    children. Compound shapes combine additive/subtractive/ignored descendant
    branches into one Boolean mask. Additional contours are supported. Layers can
    ignore their direct parent mask while retaining higher ancestor masks.
  - Fill layers: non-destructive colored fills inheriting their parent's shape.
  - Open shape layers: freeform variable-width stroked lines with caps.
  - Raster objects: sparse 256x256-tiled bitmap areas with pressure-sensitive
    pencil/eraser, explicit non-clipping interaction frames, underlay opacity,
    and ignore-parent-mask support.
  - Text objects: strict (fit-to-parent/compound, alignment/margins) or free
    (projective quad, handles visible while editing) layout; content-derived name.
  - Vector Drawing objects: pressure-sensitive cubic strokes with variable
    width/opacity, per-stroke render-revision caching, owned Vector Fill
    children, underlay, ignore-parent-mask.
  - Vector Fill objects: bounded face fills owned by a Vector Drawing
    (close-gaps, narrow areas, enclose mode, area scaling).
  - Gradient objects: ColorFillGradientObject children of shapes with
    Line/Curve, Circle/Ellipse, and Parent Shape field types, Blender-style
    ramp editing, translucent ARGB stops, per-series presets, and a built-in
    Primary-to-Secondary preset. Scalar distance fields cached independently
    from ramp colors for interactive editing.
  - Speed Lines objects: SpeedLinesGradientObject variant of gradients whose
    color ramp controls line color/opacity while a second greyscale ramp
    drives thickness. Impact-line parameters (density with auto-thickness
    scale, gap, close range, randomness distance/scale with neighbor
    smoothing) plus a deletable, non-movable custom center shape/line that
    lines converge toward (openness mismatch or Outwards mode ignores it).
    Line/curve mode adds a draggable side/length gizmo and a Parallel /
    Perpendicular text-toggle gizmo; color and speed-lines gradients coexist
    per field type.
  - Drawing selections: rectangle/lasso/stroke selection for raster pixels or
    vector points (Shift adds, Ctrl removes); 8-handle free/uniform transform,
    edge translation, rotation, movable pivot. Shared by object transforms.

All edits are backed by a full undo/redo command stack (CallbackCommand,
TilePatchCommand, ObjectPatchCommand). Projects are saved as portable folders
with atomic, versioned chapter saves and interrupted-write recovery. Schema
version is currently 13; settings version 11.

Core design principles:
  - Non-destructive: masks, fills, compound shapes, opacity compose without
    modifying child data.
  - Sparse tiles: raster strokes stored as 256x256 RGBA tiles, allocated only
    where drawn.
  - Versioned migration: documents migrate up to V12 on load.
  - Extensible registries: object and bound types registerable at runtime.
  - Canonical colors: everything normalized to #AARRGGBB.
  - Performance-aware caching: vector stroke images cached per-stroke with
    render revisions; gradient geometry vs. ramp cached independently; touch
    navigation uses grab-once snapshots with frame coalescing.


2. TOOLS (INTERACTIVE MODES)
----------------------------

  Object Select (S)       - Click to select entities; Ctrl+click shows candidate
                            menu for overlapping hits. Shapes selectable within
                            12 screen px of border; filled interiors stay
                            click-through. Vector strokes preferred over fill
                            interiors.

  Raster Pencil (P)       - Pressure-sensitive drawing (size/opacity curves,
                            density, antialiasing, taper, predictive ink).
                            Contextual: draws vector strokes on a Vector Drawing.
                            Stylus hover shows pressure-tool circle and center
                            crosshair at the active S/M/L size.

  Raster Eraser (E)       - Erase with circular/square brush; prunes empty
                            tiles. Contextual: three vector eraser modes
                            (Stroke / Point / Intersection). Real-time gesture
                            preview during the sweep.

  Fill (F)                - On shapes: border click changes outline, interior
                            click sets fill. On Vector Drawing: click/drag
                            through faces creates Vector Fill children behind
                            strokes. Enclose and Fill combines enclosed faces.
                            Close Gaps / narrow areas / area scaling settings.

  Text Edit               - Click to position cursor, drag to select, IME
                            input, clipboard paste, local undo within session.
                            Edge midpoint drag for strict margins. Free text
                            handles visible while editing.

  Transform (T)           - 8-handle free projective or uniform scaling; grid
                            snap; rotation and movable pivot; static background
                            cache for raster previews. Outside-frame translation
                            is deferred until a drag is confirmed so pencil
                            strokes on raster edges are not mistaken for moves.

  Shape Edit (B)          - Edit a bounded layer's geometry: nodes, Bézier
                            controls, gizmos (type, lock, roundness, thickness,
                            delete, cap), insertion, translation. Rectangle
                            per-corner radius with normal/free modes. Contour
                            editing. Compound construction-path editing.

  Vector Edit             - Auto-activated for a selected Vector Drawing. Blue
                            anchor circles for the selected stroke; Ctrl+click
                            extends stroke selection. Point drag with live
                            preview rendering.

  Add Rectangle / Circle  - Drag to create bounded layers (primary outline,
                            secondary fill/core).

  Add Shape               - Click for vector points, drag for Bézier, click
                            first point to close, Enter/double-click for open line.

  Add Raster / Text / Fill / Vector Drawing - create respective objects.

  Vector Redraw           - Pressure redraw for thickness/opacity with Manual
                            or Point Select interaction; Increase/Decrease/
                            Uniform operations; sliders + numeric entry; Apply
                            targets selected points, then strokes, then all.

  Vector Connect          - Sweep across two endpoints to connect with a
                            tangent bridge (keeps the first stroke's style).

  Sweep Simplify          - Translucent orange circular preview; changes only
                            the swept points and their adjoining curve spans;
                            selected points remain visible and selected.
                            Spatial anchor grid keeps gesture queries local.

  Insert Page Gap         - Adds editable 120px orange gutter between
                            physically adjacent pages.

  Drawing Selection       - Rectangle / Lasso / Stroke selection for raster
                            pixels or vector points; Shift adds, Ctrl removes,
                            unmodified replaces; Select All (Ctrl+A by default);
                            transform with handles, rotation, pivot.

  Gradient Tools          - Contextual ribbon: create Line/Curve, Circle/Ellipse,
                            or Parent Shape gradients (color or Speed Lines);
                            ramp stop editor with drag + double-click color
                            edit; distance/direction/uniform/reverse parameters;
                            preset management. Speed Lines adds a greyscale
                            thickness ramp column and an Impact Line Parameters
                            column (density/gap/close range/randomness sliders,
                            Custom Center Shape/Line button, Outwards toggle).
