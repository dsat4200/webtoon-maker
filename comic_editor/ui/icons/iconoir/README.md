# UI icons

The vendored Iconoir glyphs come from [iconoir-icons/iconoir](https://github.com/iconoir-icons/iconoir) and retain the adjacent MIT license.
`ease-curve-control-points.svg` and `text-box.svg` were added from the upstream `icons/regular` directory during the theme UI pass.

`brush.svg`, `lasso-brush.svg`, `selection.svg`, `lasso-select.svg`, and `draw-polygon.svg` are original Webtoon Maker glyphs using the same 24-pixel grid, 1.5-pixel stroke, and `currentColor` convention. They distinguish drawing and selection tools without changing the toolbar layout.
