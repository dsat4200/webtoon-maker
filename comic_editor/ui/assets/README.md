# Webtoon Maker branding

`webtoon-maker.png` is the original transparent page-and-pencil mascot.
`webtoon-maker.ico` packages it at 16, 24, 32, 48, 64, 128 and 256 pixels for
the Windows launcher, taskbar, dialogs, and integrated project toolbar.
`build-launcher.ps1` embeds the ICO in `WebtoonMaker.exe`.

Created with the built-in imagegen tool. Generation prompt: a cute cream comic
page with a folded teal corner, simple happy face, rosy cheeks, and a drawing
pencil; thick charcoal outline, compact readable silhouette, transparent
background, no lettering. The final edit removes both feet and keeps the page,
face, corner, pencil and hands unchanged.
