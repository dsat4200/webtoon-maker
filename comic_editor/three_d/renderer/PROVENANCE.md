# Embedded renderer provenance

This neutral renderer was adapted from the sibling **3D Perspective Renderer**
repository at audited commit
`d13b75fc437fad8e990c87a4e2c0d7e6bdf7e73d` (2026-08-06 integration).

Included behavior: orbit camera and quaternion math; Perspective,
Orthographic, and the Equidistant, Equisolid-angle, Stereographic, and
Orthographic-fisheye mappings; portable six-face cubemap conventions; glTF
and OBJ import concepts; grid, picking, toon/diffuse/unshaded shading,
silhouette, light, shadow, primitive, and transform-gizmo behavior.

Explicitly excluded: human/character tools, randomized views, saved projects,
frame libraries, and every asset-library type or runtime dependency.
